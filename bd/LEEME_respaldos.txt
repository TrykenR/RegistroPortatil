COPIAS DE SEGURIDAD AUTOMÁTICAS
================================

Qué protege esto
----------------
Si se daña el disco de tu computador, o alguien borra datos por error,
sin un respaldo se pierde todo el historial de accesos y los equipos
registrados. El script respaldo_diario.bat saca una copia cada día.

IMPORTANTE: un respaldo guardado en el MISMO disco no protege contra
que ese disco se dañe. Copia la carpeta de respaldos de vez en cuando
a una memoria USB, un disco externo o la nube.


PASO 1. Crear un usuario solo para respaldar
--------------------------------------------
Es mejor no usar root. Este usuario solo puede leer, no puede modificar
ni borrar nada. En la terminal:

  mysql -u root -p -P 3307

y dentro de mysql, cambiando TU_CLAVE_DE_RESPALDO por una clave tuya:

  CREATE USER 'respaldo'@'localhost' IDENTIFIED BY 'TU_CLAVE_DE_RESPALDO';
  GRANT SELECT, SHOW VIEW, TRIGGER ON autogestion_portatiles.* TO 'respaldo'@'localhost';
  FLUSH PRIVILEGES;
  exit


PASO 2. Crear el archivo de credenciales
----------------------------------------
Crea la carpeta C:\respaldos_autogestion y dentro un archivo llamado
credenciales.cnf con exactamente este contenido (con tu clave):

  [client]
  user=respaldo
  password=TU_CLAVE_DE_RESPALDO

Así la clave no queda escrita dentro del script. Que nadie más use ese
computador con acceso a esa carpeta: el archivo contiene la clave.


PASO 3. Probar el script a mano
-------------------------------
Copia respaldo_diario.bat a C:\respaldos_autogestion\ (o déjalo donde
está) y ejecútalo con doble clic. Debe aparecer un archivo
respaldo_AAAA-MM-DD_HH-MM.zip en C:\respaldos_autogestion y una línea
"OK" en respaldo.log. Si dice ERROR, revisa las rutas de las primeras
líneas del script (sobre todo RUTA_MYSQLDUMP y PUERTO).


PASO 4. Programarlo para que corra solo cada día
------------------------------------------------
Abre cmd COMO ADMINISTRADOR y ejecuta (ajusta la ruta del .bat):

  schtasks /create /tn "Respaldo Autogestion" /tr "C:\respaldos_autogestion\respaldo_diario.bat" /sc daily /st 23:00 /ru SYSTEM

Eso lo ejecuta todos los días a las 11 de la noche, aunque no haya
nadie con la sesión iniciada. Si el computador está apagado a esa hora,
ese día no se hace respaldo: elige una hora en que normalmente esté
encendido. Para probarlo ya mismo:

  schtasks /run /tn "Respaldo Autogestion"


CÓMO RESTAURAR UN RESPALDO (si algún día hace falta)
----------------------------------------------------
1. Descomprime el .zip que quieras restaurar para obtener el .sql.
2. En cmd:

  mysql -u root -p -P 3307 autogestion_portatiles < C:\ruta\respaldo_AAAA-MM-DD_HH-MM.sql

Prueba la restauración una vez en una base de prueba, antes de
necesitarla de verdad. Un respaldo que nunca se ha probado restaurar
no es una garantía.


SOBRE LOS DATOS PERSONALES (Habeas Data)
----------------------------------------
Los respaldos contienen nombres y documentos de estudiantes: trátalos
con el mismo cuidado que la base de datos. Por eso el script borra
solos los respaldos de más de 14 días (cámbialo con DIAS_A_CONSERVAR).
Si copias respaldos a un disco externo, guárdalo en un lugar seguro y
bórralos de ahí también cuando ya no los necesites.
